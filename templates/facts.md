# Confirmed facts log

The agent only claims what's on your master resume or in this file. Add a fact the moment you confirm it, dated, in the exact wording you'll stand behind. When a new entry replaces an old one, say so ("replaces the 14 Oct note"). The latest dated entry always wins.

Entry pattern:

`- **Topic (YYYY-MM-DD):** the fact. OK: "wording the agent may use". Not confirmed: what it must not claim.`

## Standing rules

These override the skill's defaults.

- Pages: 2 (maximum, never padded)
- Paper: A4 <or US Letter>
- Font: Calibri 10pt
- Availability line: <e.g. "Availability: Immediate (no notice period)", or leave out>
- Job title variants: <e.g. "Senior Software Engineer / Tech Lead" for lead roles, "Senior Software Engineer" for everything else>
- Always include these projects (optional; delete the list if projects should follow the JD):
  - <Employer (Mon YYYY – Mon YYYY)>: <project 1>; <project 2>

## First-run questions

The agent asks these before the first build. Delete this section once they're answered above.

1. For each job, how big was the team, and did you lead, manage or mentor it? Did you hire, run reviews or own a budget?
2. Which numbers on your resume are measured, and which are estimates?
3. Which tools on your resume have you only used lightly, or only in personal projects?
4. Which countries can you work in without sponsorship, and what's the exact phrase you want used?
5. Are there projects that must appear on every resume?
6. Is there anything you never want on a resume (a past employer's internal names, a client, a reason for leaving)?
