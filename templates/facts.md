# Confirmed facts log

The agent only claims what's on your master resume or in this file. Add a fact here the moment you confirm it, with the exact wording you're happy to stand behind.

## Preferences

- Name on file: <First Last>
- Pages: 2
- Paper: A4 <or US Letter>
- Font: Calibri 10pt
- Availability line: <e.g. "Availability: Immediate" or "Notice period: 1 month", or leave out>
- Work authorisation: <countries you can work in without sponsorship>
- Locations you'll accept: <cities, remote, relocation yes/no>

## Wording limits

Things that are true but easy to overstate. The agent keeps these words exactly.

- <e.g. "Mentored a team of 6". Hiring and performance reviews aren't confirmed, never say "managed".>
- <e.g. "Estimated 3x faster reporting". Keep "estimated".>
- <e.g. Kubernetes is familiarity only, never "experience with".>

## Tools with no single home

Real skills that shouldn't be placed under one specific job.

- <e.g. FastAPI, used in side projects only, Skills section only>

## Extra facts

True things that aren't on the master resume yet. Newest first.

- YYYY-MM-DD · <fact> · <which role or project it belongs to, if any>

## Questions to answer on first run

The agent asks these before the first build. Delete each one once it's answered above.

1. For each job, how big was the team, and did you lead, manage or mentor it?
2. Which numbers on your resume are measured, and which are estimates?
3. Are there tools on your resume you've only used lightly?
4. Is there anything you never want on a resume (a past employer's internal names, a client, a reason for leaving)?
